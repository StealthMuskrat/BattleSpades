# Runtime team rules and anticheat review

This batch ports the administrator HUD commands, statistical suspicion analysis and review command adapters into the standard hosted composition. The ordinary application entry point remains gated; this is another hosted migration checkpoint, not completion of the whole migration.

`/lockscore` and `/infiniteblocks` (`/infblocks`) use the original team aliases, configured names, state queries and boolean tokens. They require administrator permission. The scene owns explicit packet 81/82 values, including false values, and replays them on late joins. StateData also includes the current values. Unlocking emits a score resynchronization. Generic team score additions honor the existing lock; original direct mode score assignments retain their existing behavior. The rules survive a same-scene restart and retire with a new scene.

Infinite blocks now reaches single-block, line, flare, prefab and block-launcher authorities. Other placement, visibility, collision, cadence and bounded queue checks still apply. Queued builds retain the amount actually debited, so changing a rule between admission and cancellation cannot manufacture or lose a refund. Old life generations never refund a new wallet.

The statistical review owner observes accepted hitscan triggers and input orientation history. It records visible engagements, snap examples and fresh acquisition samples with the original bounded histories. Analysis combines profile kill counters, single-ray headshot hit rates, per-tool accuracy against the human population, aim snaps, acquisition times, chosen seeds and sustained violations. Bots do not contribute to analysis or population. Minimum samples, configurable thresholds, weighted reasons and score ordering follow the original analyzer. The seed aggregate deliberately follows the original combat counter, which records all accepted non-spade firearm seeds despite the source report's shotgun wording.

The host retains connection statistics and aim samples across scene reloads without retaining retired players/worlds. Departed human accuracies enter a bounded archive; reconnect keys suppress duplicate live/archive population samples. `/acreport [player]` lists the top five positive scores or explains one player's reasons. `/acstats <player>` exposes counters, histograms, input queue delays and aim aggregates. Both commands require administrator permission and split chat at 110 Unicode code points.

The independent second scheduler maintains the population and emits periodic flagged summaries. Immutable JSONL snapshots go to a bounded worker queue; file creation, size rotation and writes stay off the gameplay owner. Queue saturation or file failure is logged. Simulation shutdown drains journal work before closing the host. The review service does not kick or ban.

Validation is recorded in the checkpoint evidence after the consolidated checks. macOS remains deferred until the full migration is complete. Billboard/POI helpers, unofficial community modes, achievements, remaining external services and ordinary standalone hosting are outside this batch.
